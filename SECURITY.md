# Security Policy

## Supported versions

EcoDroid is pre-alpha. Only the latest commit on `develop` receives fixes.

## Reporting a vulnerability

Please do **not** open a public issue. Use GitHub's private
[security advisory form](https://github.com/uzunbugra/openEmu/security/advisories/new)
instead.

Include what is affected, steps to reproduce, and the impact you expect. You
should get a first response within 7 days.

## Scope

In scope: the macOS app, the virtual machine engine, the guest agent, the
build and update pipeline.

Out of scope: vulnerabilities in third-party Android apps or games running
inside EcoDroid, and in upstream AOSP images.
