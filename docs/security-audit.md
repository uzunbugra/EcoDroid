# Upstream security audit (Avo)

**Status:** in progress.

Before any upstream code from [Avo](https://github.com/nizwar/avo) is merged,
it is reviewed for malicious or unexpected behaviour: build scripts, network
endpoints, the Sparkle update feed, the guest agent, checked-in binaries,
dependencies and app entitlements. The findings and the final decision will
be recorded here.
